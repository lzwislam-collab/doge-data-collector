# ③：独立现货纸面盈利验证

工程机制已接入现有小时流程；真实盈利仍为 WAIT。生效时间为 2026-10-13 00:00 UTC（日本时间09:00）。旧 P2 V1、冻结生产模型、预测历史和定投保持原样。

来源为已经公开发行的配对预测与预先登记的 PAPER_LONG/NO_TRADE。1h、24h分别使用1000 USDT模拟账户；固定预约最早不重叠区间，不按结果或交易决定挑选样本。NO_TRADE保留现金，仍检查持币基准报价。生效前样本不导入。

入场必须使用公开证据之后实际请求的全新OKX盘口，在公开后10分钟内；出场采用目标时刻后25分钟内首个合格盘口。验证现货状态、数量步长、最小数量、价格步长、30秒新鲜度、20基点最大点差及1%价格带内深度。数量向下取整，零钱保留。不足深度或错过报价会阻断完整收益前缀，不能跳过亏损或漏报区间。

买入按卖盘、卖出按买盘逐档计算，已包含可见点差；另按每边0.1%手续费、0.05%额外滑点研究假设收费。压力账户将手续费、滑点加倍，并每边增加当时半点差。账户实际费率、真实成交、排队、延迟和冲击未验证。参考：[OKX官方API文档](https://www.okx.com/docs-v5/en/)。

基准为首次可执行入场后持续持有DOGE，以及零利息现金。持币不会每期重复买入收费，等待区间继续估值。策略和基准分别报告净收益、成本、超额收益与采样回撤；超过30分钟的路径缺口明确记录。采样回撤不代表连续最大回撤。

只有观察至少30天、完成至少100个到期区间，发行与到期盘口覆盖均至少90%，没有阻断/估值缺失/路径缺口，且普通与压力成本结果超过相应持币及现金，才允许独立人工审阅。该条件不自动批准实盘、不自动宣称盈利。

原始盘口及交易规则响应单独保留，账本逐条哈希链、校验Git历史尾部和快照字节；系统注册绑定审核过的代码与协议哈希。工程实时盘口测试单独存档，不计作真实前瞻区间。异常保存BLOCKED证据并使现有流程失败；没有新增定时器。
