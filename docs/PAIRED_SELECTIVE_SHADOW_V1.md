# DOGE 选择性纸面决定与同场预测 V1

本版本补齐登记和验证机制；不能把工程通过当作选择有效、70%准确率、盈利或交易许可。正式生产、P1旧版、P2及Plus原账本保留。

## ① 完整预测与选择分开

每个原生产1h/24h预测照常登记。新版本在同一事件附加挑战者方向、概率、PAPER_LONG/NO_TRADE及固定理由；不交易不删方向预测。统计分为全部到期、固定非重叠、纸面做多子集与NO_TRADE子集；缺发行/缺配对/缺报价留覆盖率分母。

固定选择条件：只做多现货纸面研究，校准代理pUP至少0.60；历史校准与未调参验证各至少100独立标签；验证Brier低于0.25；验证中被预设阈值选择的区间至少30个；收益均值的固定正态下界代理高于45bp研究成本与储备；DOGE/BTC 24h绝对收益不超过15%/12%；当时盘口不超过30秒、点差不超过20bp且双侧1%价带可见深度至少100 USDT。任一条件不足即NO_TRADE，理由在结果出现前固定。

45bp=双侧手续费10bp、半点差2.5bp、滑点5bp及额外10bp储备，属于研究假设，不是账户实际成本。概率、收益边界及阈值来自历史蜡烛标签代理；不证明未来ticker概率已校准、尾部风险受控或可成交盈利。真实授权行动始终NO_TRADE，没有下单接口。杠杆、情绪等尚无合格数值来源，不伪造特征。

## ② 冻结旧模型与同场挑战

固定逻辑回归与Platt校准，不搜索参数；按时间60%训练/20%校准/20%验证，在边界按周期剔除接触标签；历史锚点按周期非重叠，原参数80次迭代、学习率0.09、L2=0.006固定。保存训练/校准/验证样本、参数、预测特征、输入哈希及真实预发行盘口。

挑战者必须在调用原生产发行器前完成准备。使用原发行报价、原参考价、原目标时点与相同已确认特征截点；独立复算原冻结特征并逐项匹配。配对决定最多在发行后30秒内登记，任何旧预测不得补挂挑战者。准备或新系统错误仍尝试原模型发行，随后显式失败并保存诊断。

配对、模型准备快照和原发行证据同一次提交发布，读回核对。正式配对评分要求原V2合格真实报价、原GitHub服务器公开见证，并在该见证head读取到完全相同的单条配对记录和准备快照；公开见证必须早于到期。客户端提交时间不能替代这一见证。

保存哈希连接JSONL和逐ID记录。完整可达Git历史按每次追加差异检查EOF边界、哈希及唯一ID，不能删除/改写旧行或截短链尾。Git仍不是独立不可改写存储。

挑战者与冻结生产、历史多数、BTC动量、总UP和总DOWN使用同样本同结果比较。1h/24h分别统计；五基准×两周期，Bonferroni每项p≤0.005，至少30个不一致配对。100非重叠样本、30天、发行/配对/报价覆盖率≥90%、Wilson下界≥70%、基准优势及BTC状态分组足量仅进入独立人工复核；300样本/90天继续检验，不自动晋级。
