# Official framework fit assessment — 2026-10-15

Decision: reuse methodological ideas; add no Qlib, FreqAI or RD-Agent dependency to this upgrade. This is an adaptation assessment, not a benchmark of those frameworks on DOGE.

| Official source checked | Applicable idea | Existing local equivalent and decision |
|---|---|---|
| [Qlib rolling task generator](https://github.com/microsoft/qlib/blob/main/qlib/workflow/task/gen.py), [repository](https://github.com/microsoft/qlib) | Repeatable rolling tasks and consistent model/dataset/backtest workflow | `phase1_research.py`, `phase2_research_v2.py` and their archived model/registry identity already supply rolling experiments. Retain purging, separate calibration and test, and byte reproducibility. A future Qlib adapter must preserve DOGE 24/7 UTC candles, receipt time and explicit label horizons; stock calendar/benchmark assumptions cannot be imported unchanged. |
| [FreqAI running/backtesting](https://www.freqtrade.io/en/stable/freqai-running/), [lookahead analysis](https://www.freqtrade.io/en/stable/lookahead-analysis/) | Sliding train/test windows, model expiry and sliced lookahead diagnostics | Existing frozen model lifetime, exact latest closed-hour input checks and rolling train/calibration/test are reusable. Additive completeness audit strengthens input panels. Ordinary backtest/sliced indicator consistency does not prove historical source first visibility. Do not adopt adaptive live replacement or trading integration; current candidate weights and official model must remain frozen. |
| [Microsoft RD-Agent README](https://github.com/microsoft/RD-Agent), [R&D-Agent-Quant paper](https://arxiv.org/abs/2505.15155) | Structured factor/model proposals and iterative experiment feedback | Existing 36-item eligibility, grouped ablation, model registry, negative conclusions and independent assessor are the controlled equivalent. New proposals stay quarantined and count toward multiplicity; do not let an iterative search reuse an examined holdout as pristine. Official README describes Qlib-backed quant scenarios, Linux support and Docker prerequisites; installing an agent loop here adds infrastructure and selection risk without repairing missing PIT history. |

These are engineering judgments from the cited official interfaces and local inventory. No framework accuracy, profitability or compatibility claim has been tested here. A future sandbox adapter would need a new experiment identity, identical input manifest, explicit time semantics, all search trials registered, and independent out-of-sample comparison before any adoption decision.
