# 隔离行情候选准备 V1（未激活）

依据固定提交 a8a0088190bb26295e3fb4d36322fd8b15cbb546 和前轮联合审计。
本次只新增纯函数与测试，不改冻结代码、协议、系统指针、数据或生产工作流。

## 最小可靠范围

P0：新增 `available` 元数据门槛，要求来源、原响应哈希/路径、请求时间、首次接收和可用时间。
请求 ≤ 首次接收 ≤ 可用；首次接收后的陈旧度由调用方预先指定。发布时间不能晚于接收。
该门槛不读取原始文件，不验证哈希链、供应商发布时间或独立存证；不得单独称完整 PIT 证明。
真实应用前必须同时调用现有源账本原包/追加链验证，并验证预目标公开见证。

P1：`prepare` 只用 DOGE/BTC 各最近连续 25 根已闭合确认 1H。
按 `first_ingested_utc` 截止过滤，后下载的历史数据不能用于更早的模拟决策。
缺任何一根、最新小时未可用都 WAIT_SOURCE；不补零、不跳到旧窗口。
重复、时间未对齐、非有限价格、负成交量、未确认来源明确拒绝。
固定独立方向：DOGE 1H 动量、DOGE 1H 反转、BTC 1H 动量；零收益方向缺省。
24H 收益、24H 收益标准差及最近成交量/前24小时均量只留作特征，不拟合权重。
概率为 null，纸面行动始终 NO_TRADE，准备包不能冒充已发行预测。
盘口未加入行情候选，应继续用独立前瞻分组做消融。

`purged_split` 使用绝对时间、标签结束和固定 embargo 清除训练/校准跨分区标签。
它不是训练器，不证明历史数据在当时可用；调用方还须验证样本间隔与最终标签成熟。

P2：保留 V3.1 的真实 bid/ask 深度代理、每边 10bps 手续费/5bps 滑点、双倍成本、连续持币/现金。
这些已有功能不是本次新增，费用仍是研究假设；真实成交、账户费率、冲击及连续回撤未验证。

## 下一次接入前必须完成的验收

1. 单独命名空间预注册不可变代码/协议哈希、实际未来生效时间及人工30/90天审阅日期，不能沿用旧正式样本。
2. 在现有发行前准备；只绑定真实新增原事件，30秒限制，原预目标公开 head 必须包含完整准备/决定包。
3. 复用现有配对的原始报价、固定非重叠预约和公开见证；不额外创建定时触发器。
4. 对每个候选报告全部/选中/弃权及缺发行/缺特征/缺到期报价分母。缺预测不得伪造概率或历史方向。
5. 按预注册规则对正式模型、始终涨/跌、DOGE动量/反转、BTC动量做同事件配对；模型概率经独立校准后才能计算其 Brier。
6. 若将来增加成交量/波动权重或盘口，必须作为新固定候选做消融和多重比较记录，不能事后挑优覆盖 V1。
7. V3.1 配对成本后收益与同期间持币/现金、双倍成本均须验证；原始深度缺失即阻断连续前缀。

当前不接入发行器，不新增触发器，不自动晋级，不授权交易，不改变定投。
本 PR 只可验收隔离准备与防泄漏逻辑，不能验收生产覆盖率修复、预测优势或盈利。
