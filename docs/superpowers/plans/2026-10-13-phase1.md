# 第一阶段 Implementation Plan

**Goal:** 保护旧数据并交付可运行、可审计的候选研究入口。
**Architecture:** 新增独立模块和只读 Actions，复用36项治理及冻结前瞻评价器。
**Tech Stack:** Python 3.11、NumPy 2.3.5、unittest、GitHub Actions。
**Spec:** ../specs/2026-10-13-phase1-design.md
**Execution:** 本会话直接实施；用户明确要求立即执行，省略重复设计批准。

## Global Constraints
旧受控文件不修改；无新采集 cron；无正式模型晋升；历史下载不认定为 PIT。

## Review Focus
未来标签、receipt 时间、窗口泄漏、错配事件、重复/缺口、假成功产物及不完整证据晋升。

- [x] 保护：新增 phase1_research_audit.py，测试字节篡改/ledger 重复/时间错序，再生成旧文件冻结清单和质量报告。
- [x] 研究：新增 phase1_research.py，测试时序分割、训练缩放、未来扰动不变性、因子消融和receipt过滤；运行真实历史窗口研究。
- [x] 注册：登记代码/数据/政策摘要、固定参数、逐事件结果及研究状态，测试重放身份和覆盖拒绝。
- [ ] 云端：新增 phase1_research.yml，运行完整回归、保护检查、研究和结果上传，推送研究分支并创建 PR；回读真实 Actions 状态及产物。
- [ ] 审计：检查旧资产边界、独立审查、记录截止时间、阻塞及下一阶段条件。

实施记录：新增25项测试通过；完整695项本地回归通过，2项平台条件跳过。本地Python3.12.14，云端固定3.11；实验身份明确记录Python minor，因此跨版本不是同一身份。独立审查发现receipt迟到标签问题已补测修复。Windows归档换行错误已用core.autocrlf=true fixture复现并显式禁用转换。2670项旧本地文件原始字节未变；Git归档输入亦通过2670项保护检查。完整冻结历史guard通过。首次两次云端694项测试通过，指标一致但参数有约2e-16机器误差；新增12位数值合同及回归，等待修订版本的真实产物回读。云端交付及最终证据保存在交付回读结果，不预先声明修订版本成功。
